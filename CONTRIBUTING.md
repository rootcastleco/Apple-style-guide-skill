# Contributing

Contributions should improve the skill's design-review precision without reproducing third-party documentation.

## Requirements

- Keep `SKILL.md` concise and operational.
- Put detailed guidance in one-level-deep files under `references/`.
- Use original summaries and examples; do not copy substantial text from Apple documentation.
- Preserve the independent-project and trademark notices.
- Add measurable acceptance criteria to new review rules.
- Treat accessibility, localization, privacy, state coverage, and recovery as first-class design requirements.
- Do not add font files, Apple logos, SF Symbols, screenshots, or proprietary design assets.

## Validation

Package the repository with the official ChatGPT Skill packaging tool and resolve all validation errors before opening a pull request.
